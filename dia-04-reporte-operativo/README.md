# Día 4 · Reporte operativo

Evidencia **A4** · Competencia C4: diseña un reporte de dos niveles, resumen y detalle,
navegable y legible por una persona de otra área sin explicación previa.

| Horario | Bloque | Contenido |
|---|---|---|
| 08:00 | Fundamento (1h) | Percepción visual aplicada a reportes de planta: jerarquía, uso deliberado del color, elección de gráfico según la pregunta, títulos que comunican el hallazgo. |
| 09:00 | Núcleo 1 (1.5h) | Resumen en una página |
| 10:45 | Núcleo 2 (1.5h) | Detalle con filtros y trazabilidad |
| 13:15 | Laboratorio (1.5h) | Interacciones entre visuales, formato condicional, tooltips de página, marcadores, botones, navegación entre páginas |
| 15:00 | Taller (1.5h) | Reporte de dos niveles terminado y probado con un lector de otra área sin explicación previa |
| 16:30 | Cierre (0.5h) | Validación de cifras, revisión cruzada, registro de evidencia |
