## Preparación del instructor

Reabrir A2 y revisar diez relaciones. Preparar los controles de `src/data/controles-dia-03.json`, el recetario y el calendario. Pilotear en Desktop las medidas y el cambio de calendario. El laboratorio tiene dos rutas: participantes avanzados resuelven inteligencia de tiempo con autonomía; el instructor refuerza contexto con el resto.

Fundamento y núcleo: conceptos antes de fórmula, menor guía progresiva. Laboratorio: las cuatro operaciones temporales del PDF sobre calendario completo. Taller: seis indicadores definidos, documentados y comprobados.

Las cifras del material se derivan del ZIP sintético distribuido tras las reglas A1. No se entrega un PBIX ya construido: cada evidencia se desarrolla durante la clase, guardando la anterior. Para recuperación tras una ausencia, el instructor debe conservar una copia validada de cada evidencia en el espacio autorizado del grupo.
